# Aqura - 3D 网页沉浸水族箱游戏

一款基于 **Three.js** 与现代 Web 前端技术构建的 3D 沉浸式水族箱网页游戏。玩家可以投喂鱼群、互动敲击玻璃、擦除缸壁水藻、购买珍奇海洋物种与水底造景、切换灯光主题，并在优雅的水下自然声效中享受治愈的虚拟水族生活。

## 🌟 核心特性

- **3D 水族箱与光学模拟**：
  - 高透物理材质玻璃缸与实木/合金框架，具有折射感与水面反光。
  - 沙底动态程序化焦散光斑（Caustics）投影与水下丁达尔（God Rays）光束。
  - 气泡发生石粒子系统，源源不断产生浮力微气泡。
- **生动鱼类生态与 AI 游动算法**：
  - 包含小丑鱼、蓝唐王鱼、神仙鱼、斗鱼/孔雀鱼、红金锦鲤以及发光梦幻水母等多种程序化建模生物。
  - 骨骼摆动与脊柱正弦波游动系统，具有逼真的划水与摆尾动态。
  - 融合 Boids 鱼群感知算法、饥饿追踪定位、鱼食捕食判定以及受惊避障机能。
- **趣味交互与造景玩法**：
  - **投喂鱼食 (Feed)**：点击水面投放鱼食，鱼食受浮力与重力缓慢下沉，饥饿鱼儿主动寻食。
  - **轻敲玻璃 (Tap)**：敲击鱼缸玻璃产生波纹与低沉敲击音效，附近的鱼儿会机敏散开躲避。
  - **擦拭水藻 (Clean)**：拖动清洁海绵刷擦拭缸壁，去除随时间积累的藻类，恢复水质纯净度。
  - **小鱼跟随与观察 (Inspect)**：点击选中任意小鱼，镜头自动平滑平移追踪，查看小鱼名字、物种、饱腹度与心情。
  - **水族商店 (Shop)**：投喂与照料积累金币，选购更多鱼种、沉船宝箱、珊瑚礁、水草丛、气泡发生石等造景设施。
  - **灯效主题切换**：支持热带日光浅滩、深海幽蓝、暮光余晖暖金、赛博幻夜霓虹等不同氛围模式。
  - **摄影模式 (Photo Mode)**：一键隐去所有 UI，全景捕捉水族箱高清照片并下载保存。
- **程序化水下音效**：
  - 基于 Web Audio API 动态合成低频水流共鸣、上升微气泡声、投喂落水声、进食音与敲击声，100% 本地即开即用，无需加载外部音频文件。
- **本地存储持久化**：
  - 游戏金币、已购鱼种与造景、水质数据自动保存至本地 `localStorage`。

## 🎮 操作指南

| 交互工具 | 快捷操作 | 说明 |
| :--- | :--- | :--- |
| **投喂食物** | 选中工具后点击水面 | 投放鱼食颗粒，引来小鱼抢食 |
| **轻敲玻璃** | 选中工具后点击玻璃 | 敲击产生涟漪与声响，惊散附近小鱼 |
| **擦玻璃** | 选中工具后按住鼠标拖动 | 清洁水藻，恢复鱼缸水质 |
| **观察跟随** | 选中工具后点击小鱼 | 摄像机平滑聚焦追踪该小鱼 |
| **旋转视角** | 按住鼠标左键在空白处拖动 | 360° 环绕观察水族箱 |
| **缩放视角** | 鼠标滚轮滑动 | 推进或拉远观察距离 |
| **水族商店** | 点击底部黄色商店按钮 | 选购鱼种、水底造景与切换氛围灯光 |

## 🚀 启动运行

直接双击打开 `index.html` 或通过任意本地 Web 服务器（如 VS Code Live Server、Node http-server 等）启动：

```bash
# 进入目录
cd web/game/aqura

# 启动静态服务器（以 npx serve 为例）
npx serve .
```
