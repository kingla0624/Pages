# Aqura - 3D 网页沉浸蔚蓝海底

一款基于 **Three.js** 与现代 Web 前端技术构建的 3D 沉浸式开放大洋海底世界网页游戏。打破传统水族箱的玻璃边界，呈现 120m × 100m 广袤大陆架海床、360° 全景海洋大气天穹、巨型巡弋蝠鲼（Manta Ray）、56 尾远景雀鲷集群（Boids 鱼群感知）以及海月水母等生动海洋生灵。玩家可以投撒海粮、扰动洋流、唤起清澈深海洋流净化水体、探索海洋生物图鉴与海床造景，并在优雅的程序化水下环境音与远古鲸鸣中享受治愈的深海漫游。

## 🌟 核心特性

- **3D 开放大洋光学与地形模拟**：
  - 120m × 100m 广阔大陆架海床与深海断崖（Abyssal Drop-off），配合潮汐波纹与高精珊瑚沙 PBR 纹理。
  - 360° 无缝海洋大气天穹（Seamless Ocean Skydome），彻底消除水族箱方框边界。
  - 动态程序化焦散光斑（Caustics）高频投影与梯形羽化水下丁达尔（God Rays）神圣光束。
  - 750+ 浮游海雪粒子（Marine Snow）与微细气泡流，呈现充满生机的深海悬浮丁达尔感。
- **生动海洋生态与仿生生物力学算法**：
  - **巨型蝠鲼 (Manta Ray)**：鲼科胸鳍行波推进波动方程（Batoid Wave Kinematics），支持翼尖波浪舒展、转向自然倾斜横滚（Banking Roll）与长鞭尾柔美跟随。
  - **海月水母 (Moon Jellyfish)**：严格契合流体力学的双相节律脉动（0.65s 强力收缩喷流冲程 vs 1.75s 舒张滑翔冲程）与轻纱状口腕/触手柔体波动。
  - **热带珊瑚礁鱼类**：涵盖小丑鱼、蓝唐王鱼、神仙鱼、丝绸斗鱼、红金锦鲤等，基于 Catmull-Rom 样条形态学高精度建模，具备脊椎正弦行波与胸鳍划动。
  - **远景集群雀鲷 (Boids)**：56 尾青绿色蓝绿光鳃雀鲷（Chromis viridis）采用 GPU 实例化网格（InstancedMesh）高效集群游弋。
  - 融合 Boids 鱼群感知、饥饿巡航、捕食判定与受惊避障机能。
- **趣味交互与造景玩法**：
  - **投放海粮 (Feed)**：点击海面任意位置投放鱼食颗粒，微重力浮力缓慢沉降，饥饿鱼群敏锐感知并抢食。
  - **水波扰动 (Tap)**：激发水下低频水压声学扰动波，产生水波扩散与惊起鱼群向外敏捷避冲。
  - **洋流净化 (Clean)**：唤起奔涌清澈的深海洋流冲刷藻菌，恢复蔚蓝透亮水质。
  - **观察跟随 (Inspect)**：点击选中任意鱼儿或巡弋巨蝠鲼，摄像机自动平滑聚焦并在其侧上方伴游，查看小鱼名字、饱腹度与心情。
  - **海洋图鉴 (Shop)**：投喂照料积累金币，选购更多海洋物种（含巨蝠鲼、水母等）、海藻林、古陶罐、珊瑚丘与冷泉喷口等海床点缀。
  - **深海水相切换**：支持日光热带浅滩、神秘深海幽蓝、暮光余晖暖金、幻夜赛博霓虹等不同深海氛围模式。
  - **摄影模式 (Photo Mode)**：一键隐去全部 UI，全景捕捉水下无界风光高清截屏并保存。
- **纯程序化 Web Audio 水下声学合成**：
  - 100% 本地动态合成：基于滤波粉红/布朗噪声合成深海水流共鸣底噪、上升微气泡噗噜声、投喂落水声、愉悦进食音与空灵悠远的深海鲸鸣（Whale Song），零外部音频资产依赖。
- **本地存储持久化与安全性**：
  - 游戏金币、物种名录、海床造景与水质数据自动序列化保存至本地 `localStorage`。
  - 本地轻量服务内置严格的路径范围限制，防范路径穿越。

## 🎮 操作指南

| 交互工具 | 快捷操作 | 说明 |
| :--- | :--- | :--- |
| **投放海粮** | 选中工具后点击海面任意区域 | 投放海粮颗粒，吸引鱼群游来进食 |
| **水波扰动** | 选中工具后点击水体或按键交互 | 产生水波震荡与声响，惊散附近鱼群 |
| **洋流净化** | 选中工具点击触发 | 唤起深海洋流，冲刷悬浮藻类恢复水质 |
| **观察跟随** | 选中工具后点击鱼类或巨蝠鲼 | 摄像机平滑聚焦追踪伴游 |
| **旋转视角** | 按住鼠标左键在空白处拖动 | 360° 全景环绕观察开放深海 |
| **缩放视角** | 鼠标滚轮滑动 | 推进或拉远观察距离 |
| **海洋图鉴** | 点击底部图鉴按钮 | 探索物种、点缀海床造景与切换水相灯效 |

## 🚀 启动运行

直接双击打开 `index.html` 或通过本地 Web 服务器启动：

```bash
# 进入目录
cd web/game/aqura

# 启动本地开发服务器
node server.js
```

访问 `http://127.0.0.1:3456/` 即可体验。
