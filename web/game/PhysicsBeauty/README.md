# 物理之美 (The Beauty of Physics)

受[原视频《物理之美》](https://x.com/akokoi1/status/2104200939095904322/video/1)启发的实时 WebGL 视觉演绎，使用 Three.js、GLSL 和 Web Audio API。总长 76 秒，包含普朗克尺度、双缝干涉、双摆混沌、引力波、地金轨道、宇宙网、事件视界七个主题，以及回到普朗克尺度的尾声。

## 播放与画面

- 场景、字幕和 HUD 共用 `js/core/Timeline.js` 的章节时间与进度；横屏采用约 2.39:1 的电影内幅，相机、程序纹理与文字同步适配，竖屏保留完整画幅。
- 前五次章节切换采用旧画面收缩成画框、新背景虚化的过渡；旧画面继续运动，轨道年数随旧画框退出。片头保留较长收缩时间，后续门户更早淡出；后段采用渐暗，尾声撤去 HUD 并最终淡黑。
- 场景和转场共用线性离屏合成与最终色彩输出，避免切换时亮度跳变；背景使用两遍 Gaussian 模糊。单个全尺寸离屏目标最多约 419 万像素，转场结束释放额外目标。
- 动画按绝对时间计算，支持暂停、重播和任意跳转；在同一次加载中重复跳到同一时刻可复现画面。
- 音频由程序合成，包含低频音垫、扫频声与和弦。
- HUD 的“参考尺度”表示各主题的典型空间数量级，不是对相机视域的测量。

离屏预算会限制高分辨率画布的细节，放大滤波也会影响离散星点的亮度。线条按最终电影内幅的 CSS 像素宽度绘制；引力波网格先写入波面深度，避免远面与背面的线穿透叠色。浏览器验证使用 Chromium/SwiftShader；尚未验证真实设备帧率和 Safari。

## 物理模型与示意范围

- **普朗克尺度**：程序化纹理，用于表达微观泡沫的视觉意象。
- **双缝干涉**：装置缝宽、波场和粒子概率共用参数，结合路径差干涉与有限缝宽包络；固定种子使粒子积累可重现。
- **双摆混沌**：使用 RK4 积分，内部步长 0.0005 秒、历史采样间隔 0.002 秒；两组初角相差 $0.001^\circ$，物理时间以播放时间的 2.5 倍推进。
- **引力波**：轨道、网格、`strain` 与 `chirp` 共用相位和振幅模型；网格取延迟信号，音频频率放大 100 倍以便听见。时间与传播速度均为示意，不使用 LIGO 观测数据，也不求解四维时空度规。
- **地金轨道**：采用理想化的地球/金星圈数比 $8:13$（金星/地球周期比 $8/13$）和相应 Kepler 半径，展示五瓣结构；44.8 秒完成 8 年并保留到转场，年数与轨道进度共用时间函数。真实轨道并非严格闭合的整数比。
- **宇宙网**：程序化团簇、曲线纤维与有限三维空洞；镜头先退远再聚焦一个实际网络粒子，淡入暖色星系密团，并按视深柔化背景。不是观测星表或宇宙学数值模拟。
- **事件视界**：分层解析艺术投影，表现吸积盘、阴影与透镜弧；盘纹理采用有界 Kepler 径向差速与亮结剪切，不进行相对论光线或吸积流体的数值求解。2019 年 M87* 图像来自毫米波观测重建，与此可见光艺术示意不同。

## 快速启动

1. 在当前项目目录下启动本地服务：
   ```bash
   node server.js
   ```
2. 打开浏览器访问：
   ```
   http://127.0.0.1:3458/
   ```

Three.js 与网页字体从公共 CDN 加载，首次打开需要网络。

## 快捷交互操作

- **空格键 (Space)**：播放 / 暂停。
- **左右方向键 (← / →)**：快退 / 快进 5 秒。
- **M 键**：声音开 / 关。
- **F 键**：进入 / 退出全屏模式。
- **底部浮窗**：拖动进度条跳转至任意时间，或点击章节按钮跳转。
