# 物理之美 (The Beauty of Physics) - WebGL 1:1 像素级复刻工程

基于 **WebGL 2.0 / Three.js / GLSL Shader / Web Audio API** 打造的 1:1 像素级视听艺术复刻项目。
完整还原推特经典一镜到底作品《物理之美》：从 $10^{-35}\text{ m}$ 普朗克极限尺度，到 $10^{26}\text{ m}$ 可观测宇宙大尺度纤维网，再到超大质量黑洞引力奇点。

---

## 🌟 核心特性与复刻亮点

1. **一镜到底连续运镜 (One-Take Camera System)**：
   - 76 秒无缝空间尺度穿梭，全片零镜头生硬切换。
   - 三维相机沿三阶贝塞尔/样条轨迹平滑流动，视场角（FOV）自适应呼吸调整。
2. **严谨的数学物理仿真与高精度求解**：
   - **双缝干涉 (Quantum Double Slit)**：严格遵循波动光学相长/相消干涉方程，结合蒙特卡洛拒绝采样模拟单个电子随机撞击与整体概率波分布。
   - **确定性混沌 (Chaos Double Pendulum)**：采用四阶龙格-库塔法（RK4）数值求解非线性拉格朗日微分方程，精准展现两组仅相差 $0.001^\circ$ 初角的双摆急剧发散过程。
   - **引力波时空曲率 (Gravitational Waves)**：GLSL 顶点着色器实时计算双黑洞引力势阱与四维时空度规涟漪，右下角同步渲染 LIGO 探测的真实啁啾应变信号（Strain $h(t)$）。
   - **地金轨道共振 (Pentagram of Venus)**：基于开普勒二体轨道公转周期比（$8:13$），以微秒级动态线段缓冲在三维空间中交织出完美的“五瓣玫瑰线”。
   - **宇宙大尺度结构 (Cosmic Web)**：45,000+ GPU 星系质点沿三维暗物质纤维网络分布，展示可观测宇宙（930 亿光年）的宏伟图景。
   - **相对论黑洞 (Relativistic Black Hole)**：全屏光线步进（Raymarching）着色器求解强引力透镜弯折效应、吸积盘背向折射光环、相对论多普勒集束效应（Doppler Beaming）与穿越事件视界光爆。
3. **电影级科幻 HUD 包装与对数标尺联动**：
   - 顶部：`REC · ONE TAKE` 呼吸红灯、60FPS 帧精度时码（`00:00:SS:FF`）。
   - 底部：随物理尺度对数平滑滑动的标尺指针（$-35 \sim +26$）与动态物理公式。
   - 字幕：中英双语、无衬线字体优雅渐显渐隐。
4. **程序化实时音频引擎 (Web Audio API)**：
   - 零外部音频文件加载依赖，纯代码实时合成次低频宇宙音垫（Sub-bass Drone）、LIGO 啁啾扫频声（Chirp Waveform）、天体共振和弦与机械 HUD 交互反馈。

## 🚀 快速启动

1. 在当前项目目录下启动本地服务：
   ```bash
   node server.js
   ```
2. 打开浏览器访问：
   ```
   http://127.0.0.1:3458/
   ```

---

## ⌨️ 快捷交互操作

- **空格键 (Space)**：播放 / 暂停。
- **左右方向键 (← / →)**：快退 / 快进 5 秒。
- **M 键**：声音开 / 关。
- **F 键**：进入 / 退出全屏模式。
- **底部浮窗**：随时支持拖动进度条跳转至任意时间，或点击章节药丸按钮直接跳转分幕。
